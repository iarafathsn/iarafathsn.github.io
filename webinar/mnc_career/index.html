05 · Core CS skill

Problem solving
before coding.

1 · Understand

What is the actual problem? What are the constraints?

2 · Design

Break it down. Compare possible approaches.

3 · Implement

Code → test → analyze → improve.

Learn algorithms to develop your thinking — not only to pass an interview.

06 · DSA

Start simple.

ArrayLinked ListStackQueueTreeGraphHashingSortingSearching

Consistency > intensity.

1–2 good problems regularly can beat a 100-problem sprint followed by six months of nothing.

07 · Stand out

Skill → Evidence → Communication

Skill

“I know iOS development.”

Evidence

“Here are projects I built and code I can show.”

Communication

“Here is why I designed it this way and what I learned.”

Don't just say you can do it. Show it. Then explain it.

08 · Projects

Solve a real or interesting problem
Keep the scope manageable
Write the code yourself
Document what you learned
Put selected work on GitHub

10 · CV / Resume

Your CV should answer:
“Why this candidate?”

Include

Education · relevant skills · projects · internship/work · GitHub · achievements

Avoid

Fake expertise · huge technology lists · irrelevant certificates · inflated claims

Be confident about what you actually know.

11 · Applying

Don't wait for
one perfect opportunity.

Company careers

Check official openings.

Job platforms

LinkedIn · Bdjobs · university channels

Professional network

Referrals and genuine connections

13 · A practical balance

Result gets you
considered. Skill helps you
get selected.

Academic result

Maintain a good standing and don't ignore your coursework.

Technical ability

Build skills you can demonstrate through problems, projects and interviews.

Requirements vary by company, role and recruitment cycle. Always check the current job description.

14 · The AI era

AI changes the workflow.
It doesn't remove the need to think.

Don't

Problem → AI → Copy → Submit → Forget

→
Do

Think → Design → Implement → Test → Use AI → Review → Understand

15 · Question

AI gives you code.
Now what?

Understand it?

Can you explain every important part?

If not, stop and learn.
Test it?

What happens with edge cases?

Tests are your responsibility.
Challenge it?

Is this the best solution?

Review complexity and trade-offs.

17 · Final message

Don't panic about
the future.

Build your foundation. Practice consistently. Build something. Show what you can do. Use AI — but don't let AI think for you.

Your first job is not the destination. Your ability to learn, solve problems and adapt is.
